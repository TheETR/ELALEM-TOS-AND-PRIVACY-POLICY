# ELALEM — Terms and Privacy

This repository contains the public Terms and Privacy documents for **ELALEM**.

- **[Privacy Policy](PRIVACY_POLICY.md)** — what ELALEM receives, stores and
  sends to other services, plus the controls you have over your data
- **[Terms of Service](TERMS_OF_SERVICE.md)** — the basic rules for using ELALEM
  and the limits of the service

## What ELALEM is

ELALEM is a Discord bot built around music, with EMSALI AI, Economy, Fishing,
Cosmetics, Profiles, Community features, Moderation/Sentinel tools, a virtual
Marketplace and a few other utilities.

It is a hobby project run by an individual and offered free of charge. ELALEM's
virtual currency and items have no real-world value.

## Your data

The short version is simple: EMSALI only keeps long-term memories you explicitly
ask it to remember, and some sensitive categories are refused even if you ask.
AI conversation text is only sent through providers that meet ELALEM's current
privacy rules for user content.

For the full details, read the [Privacy Policy](PRIVACY_POLICY.md).

**`/deletion`** is the main place inside Discord to see, export and delete
eligible data connected to your account. Your Discord account is used as your
identity, so there is no separate form or email step for normal self-service
deletion.

Some shared or integrity-related records may remain, such as parts of completed
transactions or a server's moderation history. ELALEM shows those cases instead
of claiming everything was deleted.

`+memory` is still available when you only want to manage EMSALI memory.

When a server removes ELALEM, that server's own data is scheduled for deletion
after 30 days. Re-adding ELALEM during that window cancels the pending deletion.
A member's own global data is not removed just because one server removes the
bot.

## Contact

**For general help, privacy questions, bug reports or anything `/deletion` could
not finish, start with the
[ELALEM support server](https://discord.gg/JDKjRhpq79).**

If you cannot use the support server, you can also write to
**privacy@elalem.dev** for privacy matters. The address can receive messages,
but replies may come through another verified ELALEM contact.

If you email us, include your Discord username or user ID so we can find the
right account. If you already have a deletion reference, include that too.
